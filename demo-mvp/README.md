# 成长决策顾问 · 交互式 Demo MVP

本目录保留原 Web 界面，并已改造为**完全离线、零后端依赖的交互式 Demo MVP**（内置脱敏示例数据与内存 Mock 引擎），不再由生产后端托管。

## 如何使用

- **方式一（直接双击打开）**：直接用浏览器打开 `demo-mvp/index.html` 即可交互体验（支持对话流式输出、9 步决策、半自动记忆提案确认、语义检索、时间轴、关系图谱与速记收件箱）。
- **方式二（本地静态预览）**：
  ```bash
  python3 -m http.server -d demo-mvp 8088
  # 访问 http://127.0.0.1:8088
  ```

## 说明

- 生产使用请直接打开原生 macOS App（`成长决策顾问.app`），后端已整合进 App 内部，并支持直连 VPS 远程后端（`https://decision.sakuramu.edu.kg`）供桌面端与后续手机端共同使用。
- 本 Demo 中的全部记忆与对话均为内存虚构示例，不会读取或写入你的真实隐私记忆。
